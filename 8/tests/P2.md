# P2 tests

Executable checks are in `p2_tests.pl`. Run from the repository root with SWI-Prolog 9.x:

```sh
swipl -q -s 8/tests/p2_tests.pl -g run_tests -t halt
```

These checks require implementations of the three public predicates in `8/code/8_q2.pl`; the source scaffold alone does not satisfy them.

- `[4,2,5,3]` yields the seven sorted equation strings listed in the handout.
- `[2,4,8]` yields only `"2*4=8"`.
- `[2,3,4]`, `[]` and `[2]` yield an empty list and generation fails.
- `[0,0,0]` yields solutions without division by zero. Check the result includes `"0+0=0"` and excludes `"0/0=0"`.
- Check canonical formatting distinguishes right-associated `1+(2+3)` from left-associated `1+2+3`.
