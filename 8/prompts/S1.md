
### 1. Implement S1 my-append

> Implement only my-append using allowed Scheme forms. Recursively copy the first list onto the second, preserving order.

### 2. Implement S1 inorder

> Implement only inorder. Return the empty list for an empty tree and otherwise combine the left subtree, root value, and right subtree in that order using my-append.

### 3. Implement S1 print-inorder

> Implement only print-inorder. Display the list returned by inorder and print one newline.

### 4. Implement S1 preorder

> Implement only preorder. Return the root value followed by the left and right subtree values, using my-append. Return the empty list for an empty tree.

### 5. Implement S1 postorder

> Implement only postorder. Compute the left subtree and then the right subtree. Return their values followed by the root value, using my-append. Return the empty list for an empty tree.

### 6. Implement S1 print-all-traversals

> Implement only print-all-traversals. Print the inorder, preorder, and postorder lists in that order, with exactly one newline per list.

### 7. Implement S1 tree-stats

> Implement only tree-stats. Return a list containing height and leaf count. Use (0 0) for the empty tree and (1 1) for a leaf. For other nodes, compute each child result once and combine the results using the allowed Scheme forms.

### 8. Implement S1 print-height-and-leaves

> Implement only print-height-and-leaves. Display the two-element result of tree-stats and print one newline.

### 9. Add executable S1 tests

> Add only the S1 test file. Check all three print functions for the balanced example, right chain, symbol tree, empty tree, single node, left chain, and repeated-value tree. Compare complete output strings including final newlines.
